# France – Rental: regulations (not added yet)

Put the law text here as `regulations.txt`. Until that file exists, the app stops with "France is not set up yet".

Rules (same as Italy):
- Copy each article word for word from an official source, in the original language. Official source for France: Légifrance (https://www.legifrance.gouv.fr).
- Put a label on its own line above each article, in this exact form, so the citation check works:
  `[CITE AS: <Law name> - Art. <number>]`
  Use Code/tools/tag_citations.py as the model for adding labels.
- Add each law's short name to LAW_ALIASES in Code/base/utils/citations.py.
- Do not paraphrase or summarise the law.
